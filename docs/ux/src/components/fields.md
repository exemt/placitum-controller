# Поля ввода

Все инпуты конфигурации живут в `fields.tsx`. Новое поле — сначала сюда, не копировать `TextField` на страницу.

## Слой

| Компонент | Когда |
| --- | --- |
| `Text` | строка |
| `Num` | число без единицы |
| `SizeField` / `Bytes` | память и буферы |
| `Choice` / `Tri` / `Flag` | enum / on-off-default / boolean |
| `Chips` | список тегов |
| `Optional` | галочка «по умолчанию» в `endAdornment` поля |

`SizeField` — граница с конфигом: снаружи nginx-строка (`8m`), внутри `Bytes` всегда байты.

## Вид

- `size="small"`, ширина на всю колонку (`fieldSx`).
- Label — имя директивы (`waf_shm_zone size`), не пересказ.
- Подсказка оператору не стоит под полем: она в `FieldTooltip` (фокус и hover), со стрелкой.
- Чипы пресетов сразу под рамкой, без текстовой прослойки.
- Один chip с `default: true` (или `defaultSize` / `defaultValue`) всегда подсвечен. Текущее значение — filled.

## Текст подсказки

Строка в `config.help.*`, не JSX. Разметка:

- абзацы — пустая строка;
- `` `8m` `` — значение / единица;
- `**По умолчанию**` — ярлык.

Сначала что делает поле, затем default и оговорки (reload, restart, этап).

```
Размер shared-memory зоны. Без неё локальный слой не загрузится.

**По умолчанию** `8m`
**Reload** размер не меняет — нужен **restart**.
```

## Размер

- `onChange` у `Bytes` — `number | undefined` в байтах (1024, как nginx).
- `units` сужает селект: `["gb", "mb"]`, не весь ряд.
- `hints` — `{ label, value, default? }[]`, `value` тоже в байтах.
- Пустое поле → `undefined`, ключ из документа убирает `setKey`.

## Наследование

Поля `fields.tsx` решают одно: задан ключ или нет. На сервере и пути этого мало — ключа может не
быть потому, что значение приходит сверху. Такие поля собираются не здесь, а
[`config/InheritedRow.tsx`](../../../../ux/src/config/InheritedRow.tsx): строка сама
говорит, наследует она, переопределена или снята, и откуда пришло действующее значение.

- Редакторы для этих строк — `config/editors.tsx`, без рамки и подписи: их даёт строка.
- Галочку «по умолчанию» внутрь такой строки не ставить: две механики «ключа нет» на одном экране
  читаются как разные вещи, хотя это одна.
- Имя из каталога (`waf_deny_response_default`, набор в `waf_local_check`, формат лога) — `CatalogEdit`,
  не `Text`. Набранное руками имя ловится только на ноде.

## По умолчанию

Ключа нет в документе — модуль/nginx берёт свой дефолт. В UX это галочка **по умолчанию** (`optional` на `Text` / `Num` / `SizeField` / `Chips`, внутри — `Optional`).

- Галочка стоит в `InputAdornment` справа (рядом с единицей, через `Stack`), не отдельной рамкой.
- Галочка снята: в документ уходит значение (сначала fallback).
- С бэка пришёл ключ — галочка снята, значение с бэка.
- Ключа не было — галочка включена.
- `Tri` / `Choice` уже имеют пункт «по умолчанию» в селекте, вторую галочку не ставить.
- Шапка HTTP: **Сохранить** и **Сбросить** (пустые документы = все дефолты). «Обновить» — только у таблиц.
