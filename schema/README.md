# Схема базы

| Файл | Что это |
| --- | --- |
| `01-schema.sql` | структура: таблицы, индексы, ограничения |
| `02-seed.sql` | данные поставки: пространство `default`, справочники, страницы отказа, CRS, каталог инспекторов, порт узла, профили `default` |
| `03-geo.sh` | каталог стран и ASN из выгрузки MaxMind в `seed/`, если её положили; для базы, поднятой через initdb postgres |

Контроллер ставит `01-schema.sql` и `02-seed.sql` сам, одной транзакцией, при первом старте на
пустой базе (`src/migrate.ts`). Если схема в базе уже есть, он её не трогает. Обновлений схемы на
живой базе нет: изменилась схема — установка ставится заново.

Меняется схема — правится `01-schema.sql`, меняются данные поставки — `02-seed.sql`. Строки
данных находят пространство по имени `default`, а не по uuid.

В поставке нет серверов, путей, апстримов, сертификатов, чьих-то списков адресов и объявлений
инспекторов. Пустая установка не слушает ничего, конфигурацию заводит оператор.

## Не для установки

| Каталог | Что там |
| --- | --- |
| `seed/` | выгрузки GeoLite2 для `03-geo.sh`; в git не лежат: лицензия и размер |
| `stand/` | стендовое дерево e2e: серверы, пути, апстримы, списки и тестовые страны |
