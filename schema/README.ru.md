# Схема базы

[English](README.md) · Русский

| Файл | Что это |
| --- | --- |
| `01-schema.sql` | структура: таблицы, индексы, ограничения |
| `02-seed.sql` | начальные данные: пространство `default`, справочники, страницы блокировки и входа, CRS, каталог инспекторов, порты трафика узла, профили `default` |

Контроллер ставит `01-schema.sql` и `02-seed.sql` сам, одной транзакцией, при первом старте на
пустой базе (`src/migrate.ts`). Если схема в базе уже есть, он её не трогает. Обновлений схемы на
живой базе нет: изменилась схема — установка ставится заново.

Меняется схема — правится `01-schema.sql`, меняются начальные данные — `02-seed.sql`. Строки
данных находят пространство по имени `default`, а не по uuid.

Серверы, маршруты, апстримы, сертификаты, списки адресов и объявления инспекторов в начальные данные
не входят: их заводит оператор, а сервер самой панели создаёт установщик.
