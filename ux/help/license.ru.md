Placitum (далее — **Лицензиар**) и лицом или организацией, которые устанавливают, запускают,
изучают или изменяют ПО (далее — **Лицензиат**). Устанавливая ПО, принимая Соглашение в панели
управления или используя исходный код ПО, Лицензиат принимает условия Соглашения целиком. Если
Лицензиат не согласен с условиями, он не вправе использовать ПО.

## 1. Термины

**Placitum** — программный комплекс Placitum целиком: Открытое ядро и ПО.

**Открытое ядро** — компоненты Placitum, которые Лицензиар публикует по лицензии Apache 2.0:
модуль для nginx и агент узла, контроллер с панелью управления и API, сервис keeper, хранилище
журналов, служба ключей, справочник сетей, агенты мониторинга, общие библиотеки, установщик со
сценариями развёртывания и сборки образов, а также их документация. Открытое ядро используется на
условиях лицензии Apache 2.0. Настоящее Соглашение на Открытое ядро не распространяется и его
использование не ограничивает.

**Программное обеспечение** (далее — **ПО**) — инспекторы Placitum (в том числе IP фильтр, правила
обработки трафика, второй фактор, капча, допуск по спецификации, счётчик, классификатор, правка
ответов, куки, автодействия) и любые другие компоненты Placitum, которые Лицензиар поставляет
вместе с текстом настоящего Соглашения, с их документацией — как в виде исходного кода, так и в
виде собранных образов и исполняемых файлов. Открытое ядро, Сторонние компоненты и Ленты к ПО не
относятся.

**Инсталляция** — один контроллер Placitum вместе со всеми узлами nginx, которым он доставляет
конфигурацию, и инспекторами, которые с ним работают.

**Собственные нужды** — использование ПО Лицензиатом для защиты веб-приложений и API, которые
Лицензиат сам эксплуатирует для своей деятельности, включая коммерческую деятельность Лицензиата,
не связанную с Placitum. Приложение, которое Лицензиат эксплуатирует для своих клиентов, остаётся
его собственным приложением. Защита приложений, которые эксплуатируют третьи лица, Собственными
нуждами не является.

**Коммерческие услуги** — любая деятельность за вознаграждение или иную коммерческую выгоду,
которая состоит в установке, настройке, обслуживании, поддержке, эксплуатации или размещении ПО
для третьих лиц либо связана с ними, включая предоставление защиты ПО как услуги,
консультирование по ПО и его перепродажу.

**Платные функции** — функции ПО и отдельные компоненты ПО, которые перечислены в разделе 3 либо
отмечены Лицензиаром как платные в документации ПО или в панели управления.

**Образовательная организация** — организация любой страны, основной деятельностью которой
является обучение: школа, колледж, техникум, университет, институт, академия, учебный центр,
детский сад, библиотека, научно-исследовательская организация при них, — государственная или
частная, независимо от формы собственности.

**Ленты угроз** (далее — **Ленты**) — обновляемое содержимое, которое Лицензиар может публиковать
для Placitum: списки адресов, сетей, автономных систем, ботов и иных нежелательных источников,
репутационные данные, наборы правил, сигнатуры, модели машинного обучения и подобные материалы, а
также сервис доставки их обновлений.

**Сторонние компоненты** — программы, данные и сервисы, созданные не Лицензиаром, которые
Placitum использует, включает в свои образы или сценарии либо для работы с которыми
предназначен: nginx, Coraza, OWASP Core Rule Set, NATS, Redis, ClickHouse, PostgreSQL, MinIO,
HAProxy, базы гео- и IP-данных (например, MaxMind), источники репутации IP, модели машинного
обучения, библиотеки языков программирования и другие.

**Коммерческая лицензия** — отдельный письменный договор между Лицензиаром и Лицензиатом, в том
числе подписка, разрешающий использование ПО сверх условий настоящего Соглашения.

## 2. Бесплатная лицензия

При соблюдении Соглашения Лицензиар предоставляет Лицензиату простую (неисключительную),
действующую во всём мире, безвозмездную и непередаваемую лицензию:

1. устанавливать и запускать ПО для Собственных нужд в любом числе Инсталляций, без ограничений
   по нагрузке, по числу защищаемых приложений и узлов, по числу инспекторов и их копий;
2. делать копии ПО, необходимые для его установки, резервирования и эксплуатации внутри
   организации Лицензиата;
3. изучать исходный код ПО;
4. изменять исходный код ПО и запускать изменённые версии на тех же условиях, что и неизменённое
   ПО;
5. передавать ПО и его изменённые версии подрядчику, который устанавливает или эксплуатирует
   Инсталляцию от имени Лицензиата, при условии, что подрядчик связан обязательством не
   использовать и не распространять ПО иначе. Нужна ли самому подрядчику Коммерческая лицензия,
   определяет раздел 4.

Бесплатная лицензия не распространяется на Платные функции (раздел 3), Коммерческие услуги
(раздел 4) и Ленты (раздел 10). Все права, прямо не предоставленные Соглашением, сохраняются за
Лицензиаром.

## 3. Платные функции

3.1. На дату этой версии Соглашения Платными функциями являются:

1. вход через внешние каталоги пользователей в инспекторе второго фактора: провайдеры `ldap` и
   `ntlm` (LDAP, Active Directory, домен Windows);
2. выгрузка событий во внешние системы, например в SIEM, поставляемая отдельным компонентом.

3.2. Использование Платной функции требует Коммерческой лицензии или письменного разрешения
Лицензиара. Всё остальное в ПО покрывает бесплатная лицензия по разделу 2.

3.3. Исходный код Платных функций открыт на условиях раздела 7: его можно изучать и изменять.
Запуск Платной функции, изменённой или нет, требует Коммерческой лицензии, кроме случаев пункта
3.5 и раздела 5.

3.4. Лицензиар вправе добавлять Платные функции в новых версиях ПО. Функция, на которую
бесплатная лицензия распространялась в копии ПО, полученной Лицензиатом, остаётся под бесплатной
лицензией в этой копии и в её версиях, изменённых Лицензиатом.

3.5. Для оценки Платной функции Лицензиат вправе пользоваться ею без Коммерческой лицензии в
течение 30 (тридцати) календарных дней с первого её использования в Инсталляции.

3.6. ПО может выполнять Платную функцию, не проверяя наличие Коммерческой лицензии. Отсутствие
технического ограничения не даёт права пользоваться Платными функциями без Коммерческой лицензии.
По запросу Лицензиара Лицензиат письменно подтверждает, какие Платные функции используют его
Инсталляции.
